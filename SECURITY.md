# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in **dev-ai**, please report it responsibly.

**Do not** open a public GitHub issue for security-related problems.

Instead, contact the maintainer directly:

- Email: opensource@ehity.dev (or open a private advisory on GitHub)
- GitHub: https://github.com/Ehity/dev-ai/security/advisories/new

Please include as much detail as you can:

1. A clear description of the vulnerability.
2. Steps to reproduce it (including any required environment variables or CLI flags).
3. The affected versions and components.
4. Any suggested fix or workaround, if you have one.

We will acknowledge your report within 48 hours and keep you informed of our progress as we investigate and patch the issue.

## Scope

This policy covers the `dev-ai` Python package and its CLI commands. It does not cover third-party LLM providers (OpenAI, OpenRouter, etc.) or the models they serve — please contact those providers directly for issues related to their APIs.

Thank you for helping keep **dev-ai** safe for everyone.
